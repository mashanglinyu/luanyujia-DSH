# 文档 + 文件 + 保留位 + AI

左侧宽文档阅读区、右上文件、下方工具位、右下 AI。复盘 / 周报 / 长文阅读最舒服。

## 布局

| 位置 | 面板 | 类型 |
|---|---|---|
| 1,1 · 3×3 | 文档 | `view` |
| 4,1 · 1×3 | 文件 | `file` |
| 1,4 · 2×2 | 工具位 | `reserved` |
| 3,4 · 2×2 | AI | `harness` |

## 怎么装

1. 复制 `src/layout-doc.json` 到 `外壳\\scenarios\\`
2. 重启工作台（或顶栏 ⟳）
3. 面板右上角 → 选择会话，把 AI 面板绑到你自己的会话

## 改哪

工具位默认 `reserved`（空白），按自己的活换成 `web` / `list` / `chart`。

## 注意

- 面板 `id` 不要改：它对应面板的分区数据（窗口位置 / 滚动位置）。
- 网格默认 **4 列**；`col + w - 1 > 4` 时必须在顶层写 `"cols": 5`，否则比例会乱。
- 面板不能重叠，同一行的高度要一致。
