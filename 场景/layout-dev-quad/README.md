# 四宫格开发台

左上代码预览、右上一列文件树、左下留一个自定义位、右下 AI。程序开发 / 改脚本时最顺的摆法。

## 布局

| 位置 | 面板 | 类型 |
|---|---|---|
| 1,1 · 3×2 | 代码预览 | `view` |
| 4,1 · 1×2 | 文件 | `file` |
| 1,3 · 1×2 | 自定义位 | `reserved` |
| 2,3 · 3×2 | AI | `harness` |

## 怎么装

1. 复制 `src/layout-dev-quad.json` 到 `外壳\\scenarios\\`
2. 重启工作台（或顶栏 ⟳）
3. 面板右上角 → 选择会话，把 AI 面板绑到你自己的会话

## 改哪

左下「自定义位」是 `reserved` 面板：把 json 里这一项的 type 换成你想要的（terminal / web / list 等），或者删掉它把 AI 拉宽。

## 注意

- 面板 `id` 不要改：它对应面板的分区数据（窗口位置 / 滚动位置）。
- 网格默认 **4 列**；`col + w - 1 > 4` 时必须在顶层写 `"cols": 5`，否则比例会乱。
- 面板不能重叠，同一行的高度要一致。
