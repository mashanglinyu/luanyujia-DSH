# 双 AI 下置

上面一个大预览 + 一列文件，下面两个 AI 会话并排（比如「做」和「审」两个角色）。写东西 / 校对最顺。

## 布局

| 位置 | 面板 | 类型 |
|---|---|---|
| 1,1 · 3×3 | 预览 | `view` |
| 4,1 · 1×3 | 文件 | `file` |
| 1,4 · 2×2 | AI·做 | `harness` |
| 3,4 · 2×2 | AI·审 | `harness` |

## 怎么装

1. 复制 `src/layout-dual-ai.json` 到 `外壳\\scenarios\\`
2. 重启工作台（或顶栏 ⟳）
3. 面板右上角 → 选择会话，把 AI 面板绑到你自己的会话

## 改哪

两个 AI 面板各绑一个会话：一个负责产出、一个负责挑毛病。没两个会话就先删掉右边那个。

## 注意

- 面板 `id` 不要改：它对应面板的分区数据（窗口位置 / 滚动位置）。
- 网格默认 **4 列**；`col + w - 1 > 4` 时必须在顶层写 `"cols": 5`，否则比例会乱。
- 面板不能重叠，同一行的高度要一致。
