# 大预览 + AI

左边一个大预览窗口（图片 / PDF / 视频都能拖进来），右边一条窄的 AI 对话。最省心的通用工作台：看东西 + 问 AI。

## 布局

| 位置 | 面板 | 类型 |
|---|---|---|
| 1,1 · 3×4 | 预览 | `view` |
| 4,1 · 1×4 | AI | `harness` |

## 怎么装

1. 复制 `src/layout-preview-ai.json` 到 `外壳\\scenarios\\`
2. 重启工作台（或顶栏 ⟳）
3. 面板右上角 → 选择会话，把 AI 面板绑到你自己的会话

## 改哪

适合：看资料 / 读 PDF / 刷图 / 边看边问。

装完第一件事：把 AI 面板的会话选成你自己的（面板右上角 → 选择会话）。

## 注意

- 面板 `id` 不要改：它对应面板的分区数据（窗口位置 / 滚动位置）。
- 网格默认 **4 列**；`col + w - 1 > 4` 时必须在顶层写 `"cols": 5`，否则比例会乱。
- 面板不能重叠，同一行的高度要一致。
