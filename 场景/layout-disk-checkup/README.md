# 磁盘体检台（Windows）

左边磁盘分区卡片、右上大户排行、右下清理台账，中间 AI。装在工作台里，磁盘满了不用另开工具。

## 布局

| 位置 | 面板 | 类型 |
|---|---|---|
| 1,1 · 3×2 | 磁盘分区 | `pc-drives` |
| 4,1 · 1×2 | 大户排行 | `pc-toplarge` |
| 1,3 · 1×1 | 可清理体检 | `pc-junk` |
| 1,4 · 1×1 | 清理台账 | `pc-ledger` |
| 2,3 · 3×2 | AI | `harness` |

## 怎么装

1. 复制 `src/layout-disk-checkup.json` 到 `外壳\\scenarios\\`
2. 重启工作台（或顶栏 ⟳）
3. 面板右上角 → 选择会话，把 AI 面板绑到你自己的会话

## 改哪

这套 `pc-*` 面板是通用的（读本机盘符 + 目录体积），**只支持 Windows**；第一次打开会扫盘，慢是正常的。

## 注意

- 面板 `id` 不要改：它对应面板的分区数据（窗口位置 / 滚动位置）。
- 网格默认 **4 列**；`col + w - 1 > 4` 时必须在顶层写 `"cols": 5`，否则比例会乱。
- 面板不能重叠，同一行的高度要一致。
