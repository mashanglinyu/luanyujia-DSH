# 预览 + 文件 + 卡片 + AI

左上大预览、右上文件、左下卡片列表（项目 / 网址 / 收藏都能塞）、右下 AI。内容型场景通用。

## 布局

| 位置 | 面板 | 类型 |
|---|---|---|
| 1,1 · 3×2 | 预览 | `view` |
| 4,1 · 1×2 | 文件 | `file` |
| 1,3 · 1×2 | 卡片 | `wb-cards` |
| 2,3 · 3×2 | AI | `harness` |

## 怎么装

1. 复制 `src/layout-cards.json` 到 `外壳\\scenarios\\`
2. 重启工作台（或顶栏 ⟳）
3. 面板右上角 → 选择会话，把 AI 面板绑到你自己的会话

## 改哪

卡片位的 `wb-cards` 是通用卡片渲染器：条目写在自己场景的 json 里（`cards` 字段），点卡片走 `openPath`。没有渲染器就换 `reserved`。

## 注意

- 面板 `id` 不要改：它对应面板的分区数据（窗口位置 / 滚动位置）。
- 网格默认 **4 列**；`col + w - 1 > 4` 时必须在顶层写 `"cols": 5`，否则比例会乱。
- 面板不能重叠，同一行的高度要一致。
