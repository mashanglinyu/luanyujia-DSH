# 流程图 + 预览 + AI

左上流程图 / 画布、右上文件、左下预览、右下 AI。做工作流、写方案、排步骤时用。

## 布局

| 位置 | 面板 | 类型 |
|---|---|---|
| 1,1 · 3×3 | 流程图 | `flow` |
| 4,1 · 1×3 | 文件 | `file` |
| 1,4 · 2×2 | 预览 | `view` |
| 3,4 · 2×2 | AI | `harness` |

## 怎么装

1. 复制 `src/layout-flow.json` 到 `外壳\\scenarios\\`
2. 重启工作台（或顶栏 ⟳）
3. 面板右上角 → 选择会话，把 AI 面板绑到你自己的会话

## 改哪

`flow` 是通用流程图面板：节点/连线写在 json 里；不用流程图就换 `reserved`。

## 注意

- 面板 `id` 不要改：它对应面板的分区数据（窗口位置 / 滚动位置）。
- 网格默认 **4 列**；`col + w - 1 > 4` 时必须在顶层写 `"cols": 5`，否则比例会乱。
- 面板不能重叠，同一行的高度要一致。
